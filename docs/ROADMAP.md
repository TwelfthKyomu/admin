# План работ

Что осталось довести после аудита. Задачи разбиты по зонам, чтобы их можно было
раздать разным людям и делать параллельно: внутри зоны задачи почти не пересекаются
по файлам. Приоритет: **P1** — до роста нагрузки и реальных клиентов, **P2** —
заметно улучшает продукт, **P3** — по возможности.

Правила для всех задач — те же, что в коде сейчас: логика в `contexts/<домен>`
(`.lib.ts` → `.actions.ts` → хук), UI в `presentation/<маршрут>`, общие компоненты
в `shared`. Новый код проходит `typecheck`, `lint:ci`, `test`, `deadcode`.

## Зона A — платформа и бэкенд

| # | Задача | P | Готово, когда |
| --- | --- | --- | --- |

| A3 | Журнал обработанных событий вебхуков (`event.id`) для идемпотентности Stripe | P1 | повторная доставка события не меняет данные и пишет `ignored` |

## Зона E — локализация

Сейчас интерфейс только на русском, обвязка `next-intl` убрана: она отдавала
браузеру все словари ради меню и падала при локали `en`. Если понадобится второй
язык — вернуть `next-intl` с серверным рендером строк и только нужными
пространствами имён на клиенте; подписи меню уже собраны в
`shared/labels/navigation.ts`.
